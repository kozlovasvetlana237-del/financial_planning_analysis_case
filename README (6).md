# Финансовое планирование и анализ

Универсальный демонстрационный кейс по финансовому планированию и анализу.

Проект показывает подход к построению управленческой финансовой модели для растущего бизнеса.

## Что реализовано

- обзор ключевых финансовых показателей
- P&L
- план-факт анализ
- анализ причин отклонений
- драйверная модель бизнеса
- сценарное моделирование
- юнит-экономика
- прогноз на 12 месяцев
- управленческие выводы для менеджмента

## Основные показатели

- выручка
- валовая прибыль
- операционные расходы
- операционная прибыль
- активные клиенты
- средний доход на клиента
- CAC
- LTV
- LTV/CAC
- срок окупаемости CAC
- отток клиентов

## Сценарный анализ

Интерактивная модель позволяет оценивать влияние:

- роста клиентской базы
- изменения среднего дохода на клиента
- роста операционных расходов

## Прогноз на 12 месяцев

В кейсе реализованы:

- помесячный прогноз выручки
- прогноз операционных расходов
- прогноз операционной прибыли
- визуализация динамики
- драйверная логика прогноза

## Данные

Все данные в проекте синтетические и используются исключительно для демонстрации финансовой логики.

## Технологии

- HTML
- CSS
- JavaScript
- без внешних библиотек
- один автономный HTML-файл

## Запуск

Откройте `index.html` в браузере.

## GitHub Pages

Для публикации:

1. загрузите `index.html` и `README.md` в корень репозитория
2. откройте `Settings`
3. выберите `Pages`
4. выберите `Deploy from a branch`
5. укажите ветку `main`
6. выберите папку `/ (root)`
7. нажмите `Save`

После публикации сайт будет доступен по адресу:

`https://USERNAME.github.io/REPOSITORY-NAME/`
